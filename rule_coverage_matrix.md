# Rule Coverage Matrix

## Authoritative files
- `40k_revised.md`

## Coverage buckets
- Game setup and pre-battle sequence
- Battle rounds and phase order
- Command phase effects and battle-shock
- Movement, advance, fall back, transports, reserves
- Shooting sequence and attack resolution
- Charge sequence
- Fight sequence and alternating selections
- Stratagem timing windows
- Objective control and scoring
- Combat Patrol mission flow and declarations
- Faction overlays and patrol-specific abilities
- End-of-round and end-of-game scoring

## Requirement
Every implemented rule must record:
- source document
- source section or heading
- engine module
- automated tests
- replay test coverage
- unresolved gaps / TODOs
