## 1. Introduction to Combat Patrol

Combat Patrol is the quickest and simplest way to start collecting and playing Warhammer 40,000. Games are fought on a 44" x 30" battlefield and typically last up to one hour.

### Key Features

- **Fixed Forces**: Each player uses a pre-defined Combat Patrol (typically the contents of a Combat Patrol box)
- **No Army Building**: No need to create army lists or calculate points values
- **5 Battle Rounds**: Games last exactly 5 battle rounds
- **Battle Ready Bonus**: 10 VP awarded for a fully painted army

### What You Need

- A Combat Patrol force for each player
- A 44" x 30" battlefield
- Terrain features
- Objective markers (40mm diameter recommended)
- Dice (D6)
- Measuring device

## 2. Pre-Battle Sequence

Follow these steps in order before beginning the battle:

### Step 1: Select Combat Patrol and Enhancement

- Choose your Combat Patrol
- Your army consists of all units listed on that Combat Patrol
- The designated "Warlord" model is your WARLORD
- Select either the **default Enhancement** or the **optional Enhancement** (default recommended for new players)
- Both players declare their Combat Patrol and Enhancement choice

### Step 2: Determine Mission

- Agree on a mission or roll D6 to determine randomly:

| D6  | Mission             |
| --- | ------------------- |
| 1   | Clash of Patrols    |
| 2   | Archeotech Recovery |
| 3   | Forward Outpost     |
| 4   | Scorched Earth      |
| 5   | Sweeping Raid       |
| 6   | Display of Might    |

### Step 3: Create the Battlefield

- Set up terrain features evenly across the 44" x 30" battlefield
- Place objective markers as shown in the mission deployment map
- Ensure both sides can benefit from cover

### Step 4: Determine Attacker and Defender

- Players agree which battlefield edge is the Attacker's and which is the Defender's
- Roll off: winner decides who is Attacker and who is Defender
- This determines deployment zones

### Step 5: Declare Battle Formations

Both players secretly note down, then reveal:

1. **Patrol Squads**: Which units will use their Patrol Squads ability to split into smaller units
2. **Attached Units**: Which Leader units are attached to which Bodyguard units
3. **Embarked Units**: Which units start embarked within TRANSPORT models
4. **Reserves**: Which units start in Reserves (typically Deep Strike units)

**Combat Patrol Reserves Rules:**

- Reserves units cannot arrive in the first battle round
- Any Reserves not arrived by end of battle round 3 are destroyed
- Units embarked within destroyed transports are also destroyed

### Step 6: Deploy Armies

- Players alternate setting up units one at a time, starting with the Defender
- All models must be set up wholly within their deployment zone
- If one player finishes first, opponent deploys remaining units

### Step 7: Determine First Turn

- Roll off: winner takes the first turn

### Step 8: Resolve Pre-Battle Rules

- Players alternate resolving pre-battle abilities (e.g., Scouts)
- Player with first turn resolves their abilities first

### Step 9: Begin the Battle

- First battle round begins

### Step 10: End the Battle

- Battle ends after 5 battle rounds
- If one player has no models at the start of their turn, opponent may continue playing

### Step 11: Determine Victor

- Player with most VP wins
- Ties result in a draw
- Remember: Battle Ready army = +10 VP

## 4. Command Phase

### 4.1 Gain Command Points

- Both players gain **1 Command Point (CP)** at the start of their Command phase
- CP can be spent on Stratagems throughout the battle round

### 4.2 Battle-shock Tests

Take a Battle-shock test for each unit on the battlefield that is **Below Half-strength**:

**Below Half-strength Defined:**

- Multi-model units: Lost more than half their starting models
- Single-model units: Lost more than half their starting wounds

**How to Test:**

1. Roll 2D6
2. Compare to the unit's best Leadership (LD) characteristic
3. If result ≥ LD: Test **passed**
4. If result < LD: Test **failed** - unit is **Battle-shocked**

**Battle-shocked Effects (until start of your next Command phase):**

- Objective Control (OC) characteristic becomes **0**
- Cannot be affected by friendly Stratagems
- Must take Desperate Escape tests if they Fall Back

### 4.3 Resolve Command Phase Abilities

- Resolve any abilities that trigger in the Command phase
- Check mission rules for Command phase scoring

## 5. Movement Phase

### 5.1 Movement Options

Units NOT within Engagement Range of enemy models can:

| Move Type             | Description        | Restrictions                                         |
| --------------------- | ------------------ | ---------------------------------------------------- |
| **Remain Stationary** | Unit does not move | None                                                 |
| **Normal Move**       | Move up to M"      | Cannot end within Engagement Range of enemies        |
| **Advance Move**      | Move up to M+D6"   | Cannot shoot (except Assault weapons), cannot charge |

Units WITHIN Engagement Range of enemy models can:

| Move Type             | Description        | Restrictions                |
| --------------------- | ------------------ | --------------------------- |
| **Remain Stationary** | Unit does not move | None                        |
| **Fall Back Move**    | Move up to M"      | Cannot shoot, cannot charge |

### 5.2 Engagement Range

- **Engagement Range**: Within 1" horizontally AND 5" vertically of an enemy model
- Models cannot be set up or end Normal, Advance, or Fall Back moves within Engagement Range of enemies
- If a model cannot avoid ending within Engagement Range, it is **destroyed**

### 5.3 Normal Moves

- Each model moves up to its Move (M) characteristic in inches
- Cannot move within Engagement Range of any enemy models
- Move one unit at a time

### 5.4 Advance Moves

1. Roll 1D6 (Advance roll)
2. Add result to M characteristic for the phase
3. Move each model up to this total
4. Cannot move within Engagement Range of enemies
5. **Restrictions**: Unit cannot shoot (except Assault weapons) or charge this turn

### 5.5 Fall Back Moves

- Move each model up to M"
- CAN move through Engagement Range during the move
- Cannot END within Engagement Range
- **Restrictions**: Unit cannot shoot or charge this turn

**Desperate Escape Tests:**
Required when:

- A model moves over an enemy model during Fall Back (except TITANIC or FLY models)
- A Battle-shocked unit Falls Back (test for every model)

**Test Procedure:**

1. Roll 1D6 per model requiring test
2. On a **1-2**: One model from the unit is destroyed (your choice)
3. Same model can only trigger one test per phase

### 5.6 Reinforcements Step

During your Movement phase, units in Reserves can arrive:

- **Deep Strike**: Set up more than 9" horizontally from all enemy models
- Cannot arrive in battle round 1
- Must arrive by end of battle round 3 or be destroyed

### 5.7 Embarking

- If all models in a unit end a Normal, Advance, or Fall Back move within 3" of a friendly TRANSPORT, they can embark
- Remove the unit from the battlefield
- Units cannot embark and disembark in the same phase
- Embarked units cannot do anything or be affected by anything

## 6. Shooting Phase

### 6.1 Selecting Units to Shoot

- Select one unit at a time to shoot with
- Units within Engagement Range cannot shoot (except with Pistols)
- Units that Advanced can only shoot Assault weapons
- Units that Fell Back cannot shoot

### 6.2 Selecting Targets

- Each weapon can target a different enemy unit
- Target must be:
  - Within the weapon's Range
  - Visible to the firing model (unless Indirect Fire)
- Declare all targets before resolving any attacks

### 6.3 Making Attacks

**The Attack Sequence:**

```
┌────────────────────────────────────────────────────────────────┐
│                    MAKING ATTACKS                              │
├────────────────────────────────────────────────────────────────┤
│                                                                │
│  1. HIT ROLL                                                   │
│     Roll 1D6 per attack                                        │
│     Success: D6 ≥ BS (Ballistic Skill)                         │
│     Critical Hit: Unmodified 6 (always succeeds)               │
│     Auto-fail: Unmodified 1                                    │
│                        ↓                                       │
│  2. WOUND ROLL                                                 │
│     Compare Strength (S) vs Toughness (T)                      │
│     Roll 1D6 to wound (see Wound Roll Table)                   │
│     Critical Wound: Unmodified 6 (always succeeds)             │
│     Auto-fail: Unmodified 1                                    │
│                        ↓                                       │
│  3. ALLOCATE ATTACK                                            │
│     Opponent chooses which model is hit                        │
│     Wounded models must be allocated first                     │
│                        ↓                                       │
│  4. SAVING THROW                                               │
│     Roll 1D6 + weapon's AP modifier                            │
│     Success: Modified roll ≥ Save (Sv) characteristic          │
│     Or use Invulnerable Save (never modified by AP)            │
│     Auto-fail: Unmodified 1                                    │
│                        ↓                                       │
│  5. INFLICT DAMAGE                                             │
│     Failed save = model loses wounds equal to Damage (D)       │
│     Excess damage is lost (does not carry over)                │
│                                                                │
└────────────────────────────────────────────────────────────────┘
```

### 6.4 Wound Roll Table

| Strength vs Toughness                 | D6 Required |
| ------------------------------------- | ----------- |
| S is **TWICE** (or more than twice) T | 2+          |
| S is **GREATER** than T               | 3+          |
| S is **EQUAL** to T                   | 4+          |
| S is **LESS** than T                  | 5+          |
| S is **HALF** (or less than half) T   | 6+          |

### 6.5 Modifier Limits

- Hit rolls: Cannot be modified by more than +1 or -1
- Wound rolls: Cannot be modified by more than +1 or -1
- Saving throws: Cannot be improved by more than +1

### 6.6 Invulnerable Saves

- Some models have an invulnerable save
- Choose to use EITHER normal Save OR invulnerable save (not both)
- Invulnerable saves are **never modified by AP**
- Still fails on unmodified roll of 1

### 6.7 Benefit of Cover

When a model has the Benefit of Cover:

- Add **+1** to armour saving throws against ranged attacks
- Does **not** apply to models with Save 3+ or better against AP 0 attacks
- Does **not** apply to invulnerable saves
- Multiple instances are not cumulative

## 7. Charge Phase

### 7.1 Eligibility to Charge

A unit can declare a charge if:

- It is **not** within Engagement Range of any enemy units
- It did **not** Advance this turn
- It did **not** Fall Back this turn

### 7.2 Declaring a Charge

1. Select an eligible unit
2. Select one or more enemy units within **12"** as targets
3. Targets do **not** need to be visible

### 7.3 Charge Roll

1. Roll **2D6** - this is the maximum charge distance
2. For a successful charge, you must be able to:
   - End within Engagement Range of **every** target unit
   - NOT end within Engagement Range of any non-target enemy units
   - Maintain Unit Coherency

### 7.4 Charge Move

If successful:

- Move each model up to the Charge roll distance
- Each model must end **closer** to at least one target unit
- If possible, end in **base-to-base contact** with an enemy model
- You choose the order to move models

If failed:

- No models move
- The charge fails

### 7.5 Charge Bonus

- Units that made a successful Charge move gain the **Fights First** ability until end of turn

## 8. Fight Phase

### 8.1 Fight Order

```
┌────────────────────────────────────────────────────────────────┐
│                    FIGHT PHASE SEQUENCE                        │
├────────────────────────────────────────────────────────────────┤
│                                                                │
│  1. FIGHTS FIRST STEP                                          │
│     - Units that charged this turn                             │
│     - Units with Fights First ability                          │
│     - Players alternate, starting with player whose turn it is │
│                                                                │
│  2. REMAINING COMBATS                                          │
│     - All other eligible units                                 │
│     - Players alternate, starting with player whose turn       │
│       it is NOT                                                │
│                                                                │
└────────────────────────────────────────────────────────────────┘
```

### 8.2 Eligibility to Fight

A unit is eligible to fight if:

- It is within Engagement Range of one or more enemy units, OR
- It made a Charge move this turn

### 8.3 Fighting Sequence

**For each fighting unit:**

```
1. PILE IN
   - Move each model up to 3" towards the closest enemy model
   - Optional (don't have to move full distance or at all)

2. MAKE ATTACKS
   - Each model within Engagement Range of enemies can attack
   - Models in base-to-base contact with friendly models that are
     within Engagement Range can also attack
   - Use melee weapons (WS instead of BS)
   - Follow same attack sequence as shooting

3. CONSOLIDATE
   - After all attacks resolved, models not in base-to-base contact
     with enemies can move up to 3" towards the closest enemy model
```

### 8.4 Melee Weapon Characteristics

| Characteristic          | Description                                  |
| ----------------------- | -------------------------------------------- |
| Range                   | Always "Melee"                               |
| A (Attacks)             | Number of attacks the weapon makes           |
| WS (Weapon Skill)       | Roll required to hit (like BS but for melee) |
| S (Strength)            | Strength of the attack                       |
| AP (Armour Penetration) | Modifier to enemy saving throws              |
| D (Damage)              | Wounds inflicted per failed save             |

## 9. Weapon Abilities

### 9.1 Anti-[KEYWORD] X+

- When attacking a target with the matching keyword
- An unmodified Wound roll of X+ scores a **Critical Wound**

### 9.2 Assault

- Can be shot even if the bearer's unit **Advanced**
- When Advancing, unit can ONLY shoot Assault weapons

### 9.3 Blast

- Add **+1 Attack** for every 5 models in the target unit (rounding down)
- Cannot be used against targets within Engagement Range of any friendly units

### 9.4 Devastating Wounds

- On a **Critical Wound**, no saving throw of any kind can be made
- Attack inflicts **mortal wounds** equal to the Damage characteristic instead

### 9.5 Hazardous

- After resolving attacks, roll 1D6 per Hazardous weapon used
- On a **1**: The test fails
- Failed test: Select a model equipped with a Hazardous weapon
  - Non-CHARACTER: Model is destroyed
  - CHARACTER, MONSTER, or VEHICLE: Suffers 3 mortal wounds

**Model Selection Priority:**

1. Model that has lost wounds and is equipped with Hazardous weapon
2. Non-CHARACTER model equipped with Hazardous weapon
3. CHARACTER model equipped with Hazardous weapon

### 9.6 Heavy

- Add **+1 to Hit rolls** if the bearer's unit Remained Stationary this turn

### 9.7 Ignores Cover

- Target cannot have the Benefit of Cover against attacks with this weapon

### 9.8 Indirect Fire

- Can target units that are **not visible** to the firing model
- If target is not visible:
  - **-1 to Hit rolls**
  - Unmodified Hit rolls of **1-3 always fail**
  - Target has the **Benefit of Cover**

### 9.9 Lethal Hits

- On a **Critical Hit**, the attack **automatically wounds** (skip Wound roll)

### 9.10 Pistol

- Can be shot even if bearer's unit is within Engagement Range
- Must target an enemy unit the bearer is within Engagement Range of
- Cannot be shot alongside non-Pistol weapons (except by MONSTER or VEHICLE)

### 9.11 Precision

- When attacking an Attached unit, if a CHARACTER is visible to the attacker
- Player can choose to allocate successful wounds to that CHARACTER

### 9.12 Rapid Fire X

- Increase Attacks by **X** when targeting units within **half range**

### 9.13 Sustained Hits X

- On a **Critical Hit**, score **X additional hits** on the target

### 9.14 Torrent

- Attacks with this weapon **automatically hit** (skip Hit roll)

### 9.15 Twin-linked

- You can **re-roll the Wound roll** for attacks with this weapon

## 10. Unit Abilities

### 10.1 Deadly Demise X

- When this model is destroyed, roll 1D6
- On a **6**: Each unit within 6" suffers **X mortal wounds**

### 10.2 Deep Strike

- Unit can be set up in **Reserves** instead of on the battlefield
- Can arrive during Reinforcements step of your Movement phase
- Set up more than **9" horizontally** from all enemy models

### 10.3 Feel No Pain X+

- Each time this model would lose a wound, roll 1D6
- If result ≥ X: That wound is **not lost**
- If model has multiple Feel No Pain abilities, can only use one per wound

### 10.4 Fights First

- Units with this ability fight in the **Fights First step** of the Fight phase
- Includes units that charged this turn

### 10.5 Infiltrators

- When setting up, can be placed anywhere on the battlefield
- Must be more than **9" horizontally** from:
  - Enemy deployment zone
  - All enemy models

### 10.6 Leader

- CHARACTER units with Leader can attach to Bodyguard units
- Form an **Attached unit** before the battle
- Attached units can only contain **one Leader**
- Attacks cannot be allocated to CHARACTER models in Attached units (unless Precision)

### 10.7 Lone Operative

- Unless part of an Attached unit:
- Can only be targeted by ranged attacks if attacker is within **12"**

### 10.8 Scouts X"

- At the start of the first battle round, before the first turn
- Make a Normal move of up to **X"**
- Can include a DEDICATED TRANSPORT the unit is embarked within
- Must end more than **9" horizontally** from all enemy models
- Player with first turn moves Scouts first

### 10.9 Stealth

- If every model in a unit has Stealth
- **-1 to Hit rolls** for ranged attacks against this unit

## 11. Core Stratagems

All players can use these Stratagems. Each costs Command Points (CP).

### COMMAND RE-ROLL (1CP)

**Type:** Battle Tactic  
**When:** Any phase, just after making a roll  
**Target:** Unit or model from your army  
**Effect:** Re-roll one of the following:

- Advance roll
- Charge roll
- Desperate Escape test
- Hazardous test
- Hit roll, Wound roll, Damage roll, or saving throw
- Roll to determine number of attacks

_With fast dice rolling, select one roll to re-roll_

---

### COUNTER-OFFENSIVE (2CP)

**Type:** Strategic Ploy  
**When:** Fight phase, after an enemy unit has fought  
**Target:** One unit within Engagement Range that hasn't fought this phase  
**Effect:** Your unit fights next

---

### EPIC CHALLENGE (1CP)

**Type:** Epic Deed  
**When:** Fight phase, when selecting a CHARACTER unit to fight  
**Target:** One CHARACTER model in your unit within Engagement Range of an Attached unit  
**Effect:** All melee attacks by that model gain [PRECISION] until end of phase

---

### FIRE OVERWATCH (1CP)

**Type:** Strategic Ploy  
**When:** Opponent's Movement or Charge phase, when an enemy unit:

- Is set up, OR
- Starts or ends a Normal, Advance, Fall Back, or Charge move  
  **Target:** One unit within 24" that could shoot  
  **Effect:** Shoot that enemy unit (if visible)  
  **Restrictions:**
- Cannot target TITANIC units
- Only Hit rolls of unmodified **6** hit
- Once per turn

---

### GO TO GROUND (1CP)

**Type:** Battle Tactic  
**When:** Opponent's Shooting phase, after enemy selects targets  
**Target:** One INFANTRY unit that was selected as a target  
**Effect:** Until end of phase:

- Models have **6+ invulnerable save**
- Models have the **Benefit of Cover**

---

### GRENADE (1CP)

**Type:** Wargear  
**When:** Your Shooting phase  
**Target:** One GRENADES unit that hasn't Advanced, Fallen Back, or shot, and isn't in Engagement Range  
**Effect:** Select one GRENADES model. Select one enemy unit within 8" that is visible and not in Engagement Range of friendly units. Roll 6D6: each **4+** inflicts 1 mortal wound

---

### HEROIC INTERVENTION (1CP)

**Type:** Strategic Ploy  
**When:** Opponent's Charge phase, after an enemy unit ends a Charge move  
**Target:** One unit within 6" that could charge that enemy unit  
**Effect:** Declare and resolve a charge targeting only that enemy unit  
**Restrictions:**

- VEHICLE must be a WALKER
- Unit does NOT get Charge bonus this turn

---

### INSANE BRAVERY (1CP)

**Type:** Epic Deed  
**When:** Battle-shock step, before taking a Battle-shock test  
**Target:** That unit from your army  
**Effect:** Unit automatically passes the Battle-shock test  
**Restrictions:** Once per battle

---

### RAPID INGRESS (1CP)

**Type:** Strategic Ploy  
**When:** End of opponent's Movement phase  
**Target:** One unit in Reserves  
**Effect:** Unit arrives as if it were your Reinforcements step (including Deep Strike)  
**Restrictions:** Cannot arrive in a battle round where it normally couldn't

---

### SMOKESCREEN (1CP)

**Type:** Wargear  
**When:** Opponent's Shooting phase, after enemy selects targets  
**Target:** One SMOKE unit that was selected as a target  
**Effect:** Until end of phase, models have:

- Benefit of Cover
- Stealth ability

---

### TANK SHOCK (1CP)

**Type:** Strategic Ploy  
**When:** Your Charge phase, after a VEHICLE ends a Charge move  
**Target:** That VEHICLE unit  
**Effect:** Select one enemy unit within Engagement Range. Roll dice equal to the VEHICLE's Toughness. Each **5+** inflicts 1 mortal wound (maximum 6 mortal wounds)

## 12. Objective Markers & Scoring

### 12.1 Objective Marker Basics

- Represent tactical objectives (artefacts, supplies, communication nodes)
- Recommended: 40mm diameter markers
- Place centred on points specified by the mission
- Models can move over but cannot end on top of objective markers

### 12.2 Controlling Objectives

**Range:** A model is within range if within **3" horizontally** and **5" vertically**

**Level of Control:** Add together the Objective Control (OC) characteristics of all your models within range

**Control Determination:**

- Player with higher Level of Control = **Controls** the objective
- Equal Level of Control = Objective is **Contested**

Control is checked at the end of any phase or turn.

### 12.3 Securing Objective Markers (Combat Patrol Specific)

At the end of each Command phase, if:

- You control an objective marker, AND
- One or more non-Battle-shocked BATTLELINE units are within range

Then that objective marker is **secured** by you.

**Secured Effect:** You retain control even if you have no models within range, until opponent controls it at end of a subsequent Command phase.

## 13. Combat Patrol Missions

### Mission 1: Clash of Patrols

**Mission Rule - Retrieve Intelligence:**

- From battle round 2 onwards
- In your Command phase, select one objective marker you control
- If your WARLORD is on the battlefield (or embarked in a TRANSPORT): Gain **1 CP**
- Each objective marker can only be selected once (by either player)

**Primary Objective - Take and Hold:**

| Battle Round   | Scoring                                                         |
| -------------- | --------------------------------------------------------------- |
| 2, 3, 4        | End of Command phase: 5 VP per objective controlled (max 15 VP) |
| 5 (1st player) | As above                                                        |
| 5 (2nd player) | Same scoring, but at **end of turn**                            |

**Deployment:** Search & Destroy style with 4 objectives

---

### Mission 2: Archeotech Recovery

**Mission Rule - Irradiated Power Cells:**

- Start of battle round 3: Defender randomly selects one objective in No Man's Land = **Gamma objective**
- Start of battle round 4: Gamma objective removed; Attacker randomly selects one of remaining No Man's Land objectives = **Beta objective**
- Start of battle round 5: Beta objective removed

**Primary Objective - Recover Archeotech:**

| Battle Round  | Scoring                                                         |
| ------------- | --------------------------------------------------------------- |
| 2, 3, 4, 5    | End of Command phase: 5 VP per objective controlled (max 15 VP) |
| End of battle | If you control the last No Man's Land objective: +10 VP         |

**Deployment:** Cross deployment with objectives in No Man's Land and deployment zones

---

### Mission 3: Forward Outpost

**Mission Rule - Sabotage Enemy Comms:**

- At end of your turn: If you control the objective in opponent's deployment zone
- Until end of battle: Opponent **cannot use Command Re-roll Stratagem**

**Primary Objective - Vital Ground:**

| Battle Round   | Scoring                                                                                                       |
| -------------- | ------------------------------------------------------------------------------------------------------------- |
| 2, 3, 4        | End of Command phase: 5 VP per No Man's Land objective, 10 VP for enemy deployment zone objective (max 15 VP) |
| 5 (1st player) | As above                                                                                                      |
| 5 (2nd player) | Same scoring, but at **end of turn**                                                                          |

**Deployment:** Two objectives in No Man's Land, one in each deployment zone

---

### Mission 4: Scorched Earth

**Mission Rule - Raze and Ruin:**

- From battle round 2 onwards
- Start of Command phase: If 2+ objectives remain, you can select one you control to **raze**
- Restrictions:
  - No enemy units within 3" of the objective
  - Attacker cannot raze objective marker A
  - Defender cannot raze objective marker B
- Razed objective is removed from battlefield

**Primary Objective - Raze and Ruin:**

| Battle Round   | Scoring                                                                                                                            |
| -------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| 2, 3, 4        | End of Command phase: 5 VP if control 1+ objectives, 5 VP if control more than opponent, 10 VP if you razed an objective this turn |
| 5 (1st player) | As above                                                                                                                           |
| 5 (2nd player) | Same scoring, but at **end of turn**                                                                                               |

**Deployment:** Multiple objectives across battlefield with protected home objectives

---

### Mission 5: Sweeping Raid

**Mission Rule - Supply Lines:**

- Start of Command phase: If you control your deployment zone objective
- Roll 1D6: On **4+**, gain **1 CP**

**Primary Objective - Priority Targets:**

| Battle Round  | Scoring                                                         |
| ------------- | --------------------------------------------------------------- |
| 2, 3, 4       | End of Command phase: 5 VP per objective controlled (max 15 VP) |
| End of battle | Attacker: 5 VP for objective C, 10 VP for objective D           |
| End of battle | Defender: 5 VP for objective B, 10 VP for objective A           |

**Deployment:** Four objectives in a line or diagonal pattern

---

### Mission 6: Display of Might

**Mission Rule - Break Their Spirit:**

- Insane Bravery can only be used if the target unit is within **6"** of your WARLORD

**Mission Rule - Claim Sites:**

- Objectives in No Man's Land are **symbolic sites**
- End of Command phase: If you control a symbolic site AND one or more CHARACTER models are within range
- That site is **claimed** by those models while they remain within range

**Primary Objective - Symbolic Sites:**

| Battle Round   | Scoring                                                                                                                                                                          |
| -------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 2, 3, 4        | End of Command phase, 5 VP each for: control 1+ objectives; control 2+ objectives; 1+ symbolic sites claimed by your model; same model has claimed site for 2+ consecutive turns |

## Appendix: Glossary

| Term                    | Definition                                                                              |
| ----------------------- | --------------------------------------------------------------------------------------- |
| **Attached Unit**       | A Leader unit combined with a Bodyguard unit                                            |
| **Battle-shocked**      | Unit has OC 0, can't benefit from Stratagems, takes Desperate Escape tests on Fall Back |
| **Below Half-strength** | Unit has lost more than half its starting models (or wounds for single models)          |
| **Benefit of Cover**    | +1 to armour saves vs ranged attacks                                                    |
| **Bodyguard Unit**      | A unit that a Leader can attach to                                                      |
| **Contested**           | Objective with equal Level of Control from both players                                 |
| **Critical Hit**        | Unmodified 6 on Hit roll                                                                |
| **Critical Wound**      | Unmodified 6 on Wound roll                                                              |
| **Engagement Range**    | Within 1" horizontally and 5" vertically                                                |
| **Leader**              | CHARACTER unit that can attach to Bodyguard units                                       |
| **Level of Control**    | Sum of OC characteristics of models within range of objective                           |
| **Mortal Wound**        | Damage that bypasses saving throws                                                      |
| **Reserves**            | Units not deployed on battlefield at start of battle                                    |
| **Secured**             | Objective controlled by player with BATTLELINE unit within range                        |
| **Starting Strength**   | Number of models a unit began the battle with                                           |
| **WARLORD**             | Your army's commanding CHARACTER                                                        |
