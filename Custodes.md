## 1. Army Overview

Tristraen's Gilded Blades is an elite Adeptus Custodes Combat Patrol featuring the legendary golden warriors of the Emperor's personal guard. This force specializes in devastating melee combat, with every model being a walking tank capable of cutting through entire enemy squads.

### Army Characteristics

- **Extremely Elite**: Low model count but each model is incredibly powerful
- **Exceptional Durability**: T6-T7, 2+ saves, 4+ invulnerable saves across the board
- **Devastating Melee**: WS 2+ with high-damage weapons and Martial Ka'tah buffs
- **Flexible Offense**: Choose melee stance each fight to counter specific threats
- **No Bodyguard for Warlord**: Tristraen operates independently

### Model Count

- **Standard Configuration**: 7 models total (1 + 3 + 3)
- **Allarus Option**: 6 models total (1 + 3 + 2)

### Unit Selection Guidance

**Choose Custodian Wardens when:**

- Facing elite enemy forces (Marines, Custodes, etc.)
- Expecting monsters or vehicles (Castellan Axe deals D3)
- You need more models for objective control
- Higher total OC value needed (6 vs 4)

**Choose Allarus Custodians when:**

- Facing hordes or large units (Balistus Grenade Launcher has Blast)
- Expecting high-strength firepower (T7 is exceptional)
- Durability is more important than model count
- You want the toughest infantry possible

## 3. Faction Ability: Martial Ka'tah

### Overview

All ADEPTUS CUSTODES units in this Combat Patrol have the **Martial Ka'tah** faction ability. This represents centuries of martial training in specialized combat disciplines.

### How It Works

Each time a unit with this ability is **selected to fight**, you choose ONE of the following stances. The selected stance is active until that unit finishes making its attacks.

### Ka'tah Stances

```
┌─────────────────────────────────────────────────────────────────┐
│                      DACATARAI STANCE                           │
├─────────────────────────────────────────────────────────────────┤
│  EFFECT: Melee weapons have [SUSTAINED HITS 1]                  │
│                                                                 │
│  USE AGAINST:                                                   │
│  • Hordes and large units                                       │
│  • Low-toughness infantry                                       │
│  • When you need volume of hits                                 │
│                                                                 │
│  SYNERGY:                                                       │
│  • Vaultswords - Hurricanus (9 attacks, already Sustained 1)    │
│    → Becomes effectively SUSTAINED HITS 2                       │
│  • Guardian Spear (5 attacks per model)                         │
│  • High attack count weapons benefit most                       │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│                       RENDAX STANCE                             │
├─────────────────────────────────────────────────────────────────┤
│  EFFECT: Melee weapons have [LETHAL HITS]                       │
│                                                                 │
│  USE AGAINST:                                                   │
│  • Monsters and Vehicles                                        │
│  • High-toughness targets                                       │
│  • When wound rolls would be difficult (5+ or 6+)               │
│                                                                 │
│  SYNERGY:                                                       │
│  • Vaultswords - Behemor (S7, D2, Precision)                    │
│  • Castellan Axe (S9, D3)                                       │
│  • Critical Hits auto-wound, bypassing tough targets            │
└─────────────────────────────────────────────────────────────────┘
```

### Stance Selection Guide

| Target Type       | Recommended Stance | Reasoning                                    |
| ----------------- | ------------------ | -------------------------------------------- |
| GEQ (T3, 5+ Sv)   | Dacatarai          | Generate extra hits for more kills           |
| MEQ (T4, 3+ Sv)   | Dacatarai          | Extra hits = more wound chances              |
| TEQ (T4-5, 2+ Sv) | Either             | Depends on volume vs reliability             |
| Monsters (T6+)    | Rendax             | Auto-wound on 6s bypasses high T             |
| Vehicles (T9+)    | Rendax             | Critical importance for high T               |
| Characters        | Rendax + Behemor   | Lethal Hits + Precision = Character assassin |

### Important Notes

- Stance is chosen **when selected to fight**, not at start of phase
- Each unit chooses independently
- Can choose different stances for different units in same phase
- Stances **stack** with existing weapon abilities

## 9. Tactical Guide

### Army Strengths

1. **Exceptional Durability**
   - T6-T7 across all units
   - 2+ armour saves
   - 4+ invulnerable saves on everything
   - High wound counts per model

2. **Devastating Melee**
   - WS 2+ (hits on 2s, only fails on 1s)
   - Martial Ka'tah provides Sustained Hits 1 or Lethal Hits
   - High strength, good AP, multi-damage weapons
   - Tristraen has three weapon profiles for any situation

3. **Tactical Flexibility**
   - Choose stance each fight phase
   - Select weapon profile before attacking
   - Enhancement choice changes playstyle
   - Wardens vs Allarus changes army dynamic

4. **Quality Shooting**
   - BS 2+ on all ranged weapons
   - Assault weapons allow Advance + Shoot
   - 24" range on spears and axes
   - Pistols allow shooting in combat

### Army Weaknesses

1. **Low Model Count**
   - Only 6-7 models total
   - Losing one model hurts significantly
   - Can be overwhelmed by weight of attacks
   - Limited ability to cover multiple objectives

2. **Limited Shooting**
   - No heavy ranged firepower
   - Maximum 24" range (18" for Balistus)
   - Few shots total
   - Must close to melee to maximize damage

3. **No Bodyguard for Tristraen**
   - WARLORD is vulnerable to shooting
   - Must use terrain for protection
   - Losing Tristraen costs your best fighter

4. **Slow Compared to Threat Range**
   - 6" movement (5" for Allarus)
   - No transports
   - Must weather shooting while closing
   - Enemies can kite if faster

### General Strategy

#### Deployment

1. **Use terrain** - hide Tristraen behind cover
2. **Custodian Guard** on or near home objective
3. **Wardens/Allarus** positioned to push forward
4. **Don't spread out** - concentrate force for mutual support

#### Turn 1

- **Advance aggressively** if no clear shooting threat
- **Use Inescapable Vengeance** to cover ground faster
- Position for Turn 2 charges
- Keep Tristraen concealed

#### Turn 2+

- **Declare charges** on priority targets
- Use **Overawing Magnificence** to disrupt enemy charges
- **Focus fire** - destroy one enemy unit at a time
- Don't split your force chasing multiple objectives

#### Combat

- **Choose Ka'tah stance** based on target
- **Dacatarai** vs infantry hordes
- **Rendax** vs monsters/vehicles or when wounds are hard
- Use **The Gilded Spear** for 6" pile-ins to reach more enemies
- Use **Counter-Offensive** to interrupt enemy attacks

#### Objective Play

- **Custodian Guard** secure home objectives (BATTLELINE)
- Push Wardens/Allarus and Tristraen forward
- **Watchman of Terra** gives Tristraen OC 4 in combat
- Remember: secured objectives stay yours even if you leave

### Matchup Considerations

#### vs. Hordes (Orks, Tyranids, Guard)

- Choose **Allarus Custodians** for Blast weapons
- Use **Dacatarai Stance** for Sustained Hits
- **Tristraen's Hurricanus** profile (9 attacks + Sustained)
- Expect to be charged - use **Overawing Magnificence**
- **Consecrated Ground** secondary for max VP

#### vs. Elite (Marines, Custodes, Knights)

- Choose **Custodian Wardens** for Castellan Axe
- Use **Rendax Stance** for Lethal Hits vs tough targets
- **Tristraen's Victus** profile vs vehicles
- **Tristraen's Behemor** profile vs characters
- **Raise the Vexillas** secondary for positioning

#### vs. Shooting Armies (Tau, Guard, Eldar)

- **Advance aggressively** - don't get shot to pieces
- Use **Go to Ground** when targeted
- Get into melee ASAP to stop shooting
- Use **Inescapable Vengeance** to close distance
- Hide Tristraen until you can charge
